# global_input

全局输入插件，提供两类节点：

- `全局输入`：把一个已连接的值广播到同类型的未连接输入。
- `屏蔽广播`：占位输出节点，用来阻断某一路全局广播。

## 搜索

节点搜索支持：

- `lx`
- `灵犀`
- `全局输入`
- `屏蔽广播`
- `GlobalInput`
- `BroadcastBlock`

## 说明

- 分类保留为 `🅻🆇 灵犀/全局输入`
- `屏蔽广播` 只有输出，没有输入
- `全局输入` 支持常见的 ComfyUI 类型广播，例如 `IMAGE`、`MODEL`、`CLIP`、`VAE`、`CONDITIONING`、`LATENT`、`MASK` 等，前提是目标输入本身类型兼容且未显式连线

## 备注

这个插件是在原有全局广播逻辑基础上整理、改名、清洗后收编到灵犀节点体系里的版本。

# ComfyUI 组控插件

这是一个纯前端 ComfyUI 组控插件，只注册画布虚拟节点，不参与后端推理。

## 节点

### 组控开关

- 列出当前工作流里的 group 组框。
- 每行显示组名、开关、定位按钮。
- 右键菜单支持标题过滤、排序、关闭方式、切换规则、定位按钮显示、刷新组列表。

### 组状态发送

- 读取自己所在 group 的开关状态。
- 输出端口显示为 `REPEATER`。
- 支持连线传递和广播名称传递。

### 组状态接收

- 接收 `REPEATER` 状态，控制自己所在 group。
- 可继续输出同样状态，方便串联。
- 关闭方式可跟随发送，也可固定忽略或固定禁用。

## 规则

- 用节点中心点判断所在 group。
- 多个 group 重叠时，选择面积最小的 group。
- 改变 group 状态时，会跳过本插件自己的节点。
- 开启对应 ComfyUI 的 Always。
- 忽略对应 Bypass。
- 禁用对应 Never / Mute。

## 安装

当前已集成到灵犀节点合集，路径为：

```text
ComfyUI/custom_nodes/ComfyUI-LX-Nodes
```

重启 ComfyUI，并在浏览器里强制刷新页面。如果仍然看到旧英文节点名，清一下浏览器缓存或用 Ctrl+F5 刷新。

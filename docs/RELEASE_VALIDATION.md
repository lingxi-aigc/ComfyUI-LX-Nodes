# 验收记录

## 0.1.0-rc.4 公开候选版

### 首发安装验收

使用 Windows、ComfyUI `0.46.2`、前端 `1.59.6` 和 Python `3.12.10`。将首发源码放入独立的 `custom_nodes`，用 ComfyUI 的 Python 核验基础依赖，以 CPU 模式启动独立实例。

- 加载了 56 个插件后端节点和 66 个前端脚本。验收环境只启用了这一个自定义节点包。
- 工作流管理接口能够读取独立用户目录中的示例文件。
- 提交基础文本工作流后，展示文本节点正确返回了输入内容。
- 读取演示 PNG 并保存到另一个目录，原文件名、两级子目录、尺寸、格式及像素均保留。计数重置接口返回成功。
- 项目检查和 13 项自动测试通过，包含发布文件、第三方声明、示例资源和文件夹计数接口的检查。

本次首发的安装验收覆盖基础依赖、插件注册、前端资源和无模型示例。GPU 模型推理、付费 API、语音和抠图可按需另行复验。 [复验步骤](RELEASING.md)

### 较早的界面测试

较早的本机测试使用 Windows、ComfyUI `0.46.2` 和前端 `1.59.6`，覆盖工作流侧栏排序与删除、Qwen 多图编辑画布。侧栏、智能排版和 TXT 批量进度的 README 配图使用隔离的 ComfyUI 用户目录和演示数据。
